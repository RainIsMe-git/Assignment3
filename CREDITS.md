# Credits

- **Concept and direction:** the student chose a real-camera hand gesture game and a first-person wizard theme in discussion with OpenAI Codex.
- **AI assistance:** OpenAI Codex generated the initial source, procedural artwork, tests, and documentation in this collaboration. See `PROCESS.md` for the scope and design choices.
- **Gesture recognition:** Google MediaPipe Tasks Vision, `@mediapipe/tasks-vision` version 0.10.14. [Official repository](https://github.com/google-ai-edge/mediapipe), licensed under [Apache License 2.0](https://github.com/google-ai-edge/mediapipe/blob/master/LICENSE).
- **Pretrained model:** Google MediaPipe Gesture Recognizer, float16 version 1. [Official task and model documentation](https://developers.google.com/edge/mediapipe/solutions/vision/gesture_recognizer). The game downloads the model from Google's hosted asset; it does not claim to have trained it. Review the provider's model terms before redistributing a copy.
- **Implementation reference:** Google's [Gesture Recognizer guide for JavaScript](https://developers.google.com/edge/mediapipe/solutions/vision/gesture_recognizer/web_js) informed the model setup, gesture labels, landmarks, and video inference integration. The spell rules, interface, game scoring, and scene are project-specific additions.
- **Asset delivery:** jsDelivr serves the pinned recognition library and WebAssembly assets; Google Cloud Storage serves the model.
- **Visuals and sound:** the courtyard, perspective renderer, crystal targets, glove, emblem, particles, and synthesised tones are generated by this project's code. There are no borrowed image, video, font, music, or recorded voice assets. Fonts use local system fallbacks. Screenshots depict this game.
- **Course examples:** no course example code or external gameplay tutorial was supplied or copied into this prototype.
- **Testing tools:** Node's built-in test runner; browser verification uses the development environment's Playwright and Chrome installation, which are not runtime dependencies.
